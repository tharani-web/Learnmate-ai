 Learnmate AI 🎓🤖

Learnmate AI is an AI-powered learning platform designed to help students learn smarter and more effectively.

 Features
- 🤖 AI-powered learning assistance
- 📚 Personalized learning support
- 💬 AI chatbot for student queries
- 📝 Learning resources and guidance
- 🎯 Helps students choose suitable learning paths
- 🌐 Simple and user-friendly interface

Technologies Used
- HTML
- CSS
- JavaScript
- React
- Gemini AI
- Vite

Purpose
The main goal of Learnmate AI is to provide students with personalized and accessible AI-based learning support.
